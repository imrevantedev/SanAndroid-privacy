SanAndroid

Política de privacidad

1. Introducción

SanAndroid es una aplicación gratuita para Android que muestra el santoral (los santos de cada día), ofrece un widget con los santos del día y avisa de qué contactos de tu agenda celebran hoy su santo para que puedas felicitarles.

Esta política explica qué datos usa la aplicación y qué hace con ellos.

Resumen: SanAndroid no recoge, no guarda en servidores ni comparte ningún dato personal. La aplicación ni siquiera tiene permiso para conectarse a Internet: todo funciona dentro de tu teléfono.

2. Datos que usa la aplicación

Contactos. Con tu permiso, la aplicación lee los nombres de tu agenda para compararlos con los santos del día, y el móvil y el correo de esos contactos para mostrar los botones de felicitar. Esta lectura se hace solo en tu teléfono, en el momento de mostrar el widget, el aviso o la lista de contactos. Los contactos no se copian a ningún sitio ni se envían fuera del dispositivo.

Santoral. La lista de santos viene incluida en la aplicación y se guarda en una base de datos local del teléfono. No contiene datos personales.

La aplicación no usa publicidad, ni herramientas de análisis, ni identificadores de publicidad, ni ubicación.

3. Permisos

  • READ_CONTACTS — para saber qué contactos se llaman como el santo del día. Si no lo concedes, la aplicación sigue mostrando el santoral, pero no puede avisarte de quién celebra su santo.
  • CALL_PHONE — para llamar directamente al contacto cuando pulsas el botón de llamar. Si no lo concedes, se abre el marcador con el número puesto.
  • POST_NOTIFICATIONS — para mostrar el aviso diario de los contactos que celebran su santo.

Puedes retirar cualquiera de estos permisos en cualquier momento desde los ajustes de Android.

4. Felicitar por SMS, WhatsApp, correo o llamada

Cuando pulsas uno de los botones de felicitar, SanAndroid abre la aplicación correspondiente de tu teléfono (Teléfono, Mensajes, WhatsApp o tu aplicación de correo) con el número o la dirección del contacto y un mensaje de felicitación ya escrito. El mensaje lo envías tú desde esa aplicación; a partir de ese momento se aplica la política de privacidad de la aplicación que uses.

5. Menores

La aplicación no está dirigida específicamente a menores y no recoge datos de nadie, tampoco de menores de edad.

6. Cambios en esta política

Si la aplicación cambia la forma de usar los datos, esta página se actualizará y se indicará la nueva fecha.

7. Contacto

Para cualquier duda sobre esta política puedes escribir a imrevante@gmail.com.
